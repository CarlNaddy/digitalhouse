## 3. Pricing engine

- [ ] 3.1 `Features/Marketplace/PricingEngine.cs` — `PriceAt(Product product, DateTimeOffset t): long` (micros): `ageYears = (t - CreatedAt).TotalSeconds / options.SecondsPerYear`; `drift = BasePriceMicros * pow((double)AnnualFactor, ageYears)`; `bucket = floor(t.ToUnixTimeSeconds() / 600)`; `u = DeterministicNoise.Unit(PriceSeed, bucket)` in `[-1,1]`; `wobble = 1 + (double)NoiseAmplitude * u`; clamp to floor/ceiling; `Math.Max(BasePriceMicros, (long)Math.Round(...))`. Verify xUnit tests: at age 1yr with a neutral bucket the price ≈ `base * AnnualFactor`; never below base; wobble within `NoiseAmplitude` of drift.
- [ ] 3.2 `Features/Marketplace/DeterministicNoise.cs` — `Unit(long seed, long bucket): double` in `[-1, 1]` via `SHA256.HashData`. Verify a test asserts identical output for identical inputs and a roughly uniform spread across many buckets.

- [ ] 3.4 `PricingEngine.AdminAdjustAsync(Product, long newBaseMicros, CancellationToken)`: update `BasePriceMicros`, append `PricePoint` `Cause=Admin`, recompute. Verify a `DatabaseTest`.
- [ ] 3.5 `PricingEngine.GrowthLast12Months(Product): long` (cents) = `round((PriceAt(now) - PriceAt(max(now.AddYears(-1), CreatedAt))) / 10_000)`. Verify xUnit tests for a >1yr product and a <1yr product.

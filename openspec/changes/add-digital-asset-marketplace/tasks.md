## 3. Price curve & engine

- [ ] 3.1 `Features/Marketplace/PriceCurve.cs`: `const` fields (`K=5`, `SecondsPerYear`, `BaseMicros=1_000_000`, drift/vol ranges, `BasePeriodYears`, `PeriodRatio`, `AmpBase`, `AmpRatio`, jitter range). `FromSeed(long): PriceCurve` derives `_drift`, `_vol`, and `K` components `{Period, Amp, Phase}` from `SHA256.HashData` of `"{seed}:{field}:{k}"`; the constructor precomputes `_oscAtZero`. `PriceMicrosAt(double ageSeconds): long` = `round(BaseMicros * exp(drift*y + vol*(Osc(y)-oscAtZero)))` with `y = Math.Max(0, ageSeconds/SecondsPerYear)`, clamped to `long.MaxValue`. (Pure — no DB, no clock.)
- [ ] 3.2 `PriceCurveTests` (pure unit tests): anchor (`PriceMicrosAt(0) == 1_000_000` for 50 random seeds); negative age → `1_000_000`; determinism (same seed+age across calls and across two `FromSeed`); seed variety (two seeds → > 5% mean divergence over year-5 samples); non-linearity (log-price second differences over 4 years are not all within a tight band); long-run drift (mean price over year-10 samples > mean over year-1 samples for 30 seeds); no overflow / always > 0 across 0..25 years.
- [ ] 3.3 `Features/Marketplace/PricingEngine.cs` — `PriceAt(Product p, DateTimeOffset t): long` → `PriceCurve.FromSeed(p.PriceSeed).PriceMicrosAt((t - p.CreatedAt).TotalSeconds)`. Verify a test: `PriceAt(p, p.CreatedAt)` is `1_000_000`; `PriceAt` for a 5-years-old product is well above `1_000_000`.
- [ ] 3.4 `PricingEngine.RecomputeAsync(Product, CancellationToken)`: transaction + `SELECT … FOR UPDATE` the product row, set `CurrentPriceMicros = PriceAt(product, timeProvider.GetUtcNow())` inside `using db.AllowPriceWrites()`, append a `PricePoint` `Cause=Scheduled`. Verify a `DatabaseTest` asserts the cache and one snapshot are written and match `PriceAt(now)`.
- [ ] 3.5 `PricingEngine.GrowthLast12Months(Product): long` (cents) = `round((PriceAt(now) - PriceAt(max(now.AddYears(-1), CreatedAt))) / 10_000)`. Verify xUnit tests (fixed `FakeTimeProvider`) for a >1yr product and a <1yr product.
- [ ] 3.6 Architecture test scanning `Features/`, `Components/`, `Endpoints/`, `Data/`: assert no file outside the allowlist (`Data/Product.cs`, `Features/Marketplace/PricingEngine.cs`, `Data/Seed/MarketplaceSeeder.cs`, `Features/Marketplace/ProductAdminService.cs`, `tests/DigitalHouse.Tests/TestData/ProductBuilder.cs`) assigns `Product.CurrentPriceMicros` / `.PriceSeed` / `.CreatedAt` / `.PublicId`.
